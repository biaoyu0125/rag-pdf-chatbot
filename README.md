# RAG PDF Chatbot

## Overview

This project is a Retrieval-Augmented Generation (RAG) chatbot developed as part of my professional learning plan.

The application allows users to upload a PDF document and ask questions based on the document content. It uses a large language model together with document retrieval to generate more context-aware answers.

This project supports my professional development goal of becoming an AI Engineer or Machine Learning Engineer by improving my practical skills in Generative AI, software development tools, and applied machine learning workflows.

## Project Objectives

The objectives of this project are to:

- Develop a practical Generative AI application
- Learn how Retrieval-Augmented Generation works
- Use LangChain to connect document processing and language models
- Use ChromaDB as a vector database
- Build an interactive interface using Streamlit
- Document the project professionally using GitHub

## Technologies Used

- Python
- Streamlit
- LangChain
- OpenAI API
- ChromaDB
- PyPDF
- GitHub

## Key Features

- Upload PDF documents
- Extract and process PDF text
- Split text into smaller chunks
- Generate embeddings
- Store embeddings in a vector database
- Retrieve relevant document sections
- Answer user questions using an LLM
